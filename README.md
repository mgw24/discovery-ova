# Discovery-OVA

Discovery-OVA is a portable Ubuntu Server Minimal appliance for network discovery, monitoring, remote diagnostics, packet capture, infrastructure visibility, and browser-based remote access.

The project is designed to be built as a VMware OVA and deployed as a self-contained infrastructure troubleshooting appliance.
